# V1 evidence - per-stage timings and peak memory in meta.json
Date: 2026-11-22
Branch: feature/verification

Scope: `cartog analyze --timings` records one wall-time duration per pipeline
stage plus process peak memory in `meta.json`, prints a timing table, and leaves
every deterministic artefact byte-identical when the flag is off or on.

- `tests/test_timings.py` (new): the two tests below.
- `docs/dev/PACKAGE_LAYOUT.md`: `cartog/core/timing.py` row (layout guard).

## Commit hygiene note

The first V1 commit accidentally staged `.scratch/v1-check/` because `.scratch/`
was not in `.gitignore`. The tree is never rewritten: a follow-up commit
(`git rm -r --cached .scratch`, plus `.scratch/` in `.gitignore`) removes the
scratch output from the index so later tasks cannot repeat it.
