1. PROBLEM & DIAGNOSIS
--------------------------------------------------------------------------------
find_flow_candidates() in cartog/views.py matched route candidates only when the
target string was an exact string match for node.name (e.g. 'GET, POST /users' !=
'GET /users'). When querying a specific HTTP method on a multi-method route,
find_flow_candidates() returned 0 candidates.
Additionally, candidate partitioning between active scopes (source/internal) and
excluded scopes (tests, examples, docs) was verified, alongside the CLI candidate
picker output and exit codes.
