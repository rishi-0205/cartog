- typing.py (samples/flask/src/flask/typing.py:6):
  Contains `if t.TYPE_CHECKING: ...`.
  In cartog/views.py:129-157 (_is_python_constants_or_types), AST statements allowed are Import, ImportFrom, Expr(Constant str), ClassDef (with allowed type bases), and Assign/AnnAssign.
  Line 156: `return False, f"Contains non-constant statement '{type(stmt).__name__}'"` triggers on ast.If!
  Because ast.If is not handled in _is_python_constants_or_types, typing.py is rejected and not classified as noise.
- globals.py (samples/flask/src/flask/globals.py:8, 41-60):
  Contains `if t.TYPE_CHECKING: ...` (triggers ast.If rejection) AND runtime context proxy initialization calls (`app_ctx = LocalProxy(...)`), which are ast.Call expressions, disqualifying it from constants/types.
- __main__.py (samples/flask/src/flask/__main__.py:3):
  Contains executable statement `main()`, which is an ast.Expr(ast.Call), correctly disqualifying it from being considered a barrel or constants/types module (it is an entrypoint execution script).

Conclusion: Milestone 9 is PARTIAL. The noise filtering infrastructure and CLI flag are implemented and functional for re-export barrels and simple constant/type files, but Python constants/types heuristics fail on files containing `if TYPE_CHECKING:` guards.
