What the fix does:

* `cartog/core/output.py` gains `OutputPathError`. `RunLayout` now routes every
  writer through `_confined_path()`, which rejects absolute paths and any path
  whose `Path.resolve()` is not `run_dir` or below it, then writes to and
  returns that resolved path. The junction case is caught because `resolve()`
  follows the link before the containment test.
* `cartog/scan/walk.py` prunes a directory when it is a symlink **or** a Windows
  junction (the latter reports `is_symlink() == False`), and skips a symlinked
  file whose target resolves outside the repository. Each skip is recorded in
  `ScanResult.skipped` with a reason.
* `sanitize_project_name()` compares the stem before the first dot against the
  Windows reserved set, so `CON.txt`, `LPT1.log` and friends get the `_` prefix;
  it re-applies the length cap after prefixing.
