## Split
git mv cartog/cli.py cartog/cli/__init__.py, then the body moved out:
- cartog/cli/shared.py: app, console, version_callback, main callback, _execute_parse,
  _resolve_scip, _format_scip_fail_line, _resolve_graph
- cartog/cli/commands/{doctor,parse,scip,build,map,check,flow,digest,view,queries}.py:
  one module per command; queries.py owns the query sub-app and callers-of/callees-of
- cartog/cli/__init__.py: re-exports app, console and the helpers, then imports the
  command modules for their registration side effects
The console entry point stays cartog.cli:app (verified in the built entry_points.txt).

## Behaviour fixes found by the suite
Two tests patched cartog.cli._resolve_scip. The command modules now bind that helper in
their own namespace, so the patches targeted attributes nothing reads. The tests patch
cartog.cli.commands.scip._resolve_scip and cartog.cli.shared._resolve_scip instead; every
assertion and expected output is unchanged.
