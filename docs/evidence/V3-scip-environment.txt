## Mechanism proof: the `python3` copy is the only difference

Command: two manual `scip-python index` runs with the same `VIRTUAL_ENV` and
`PATH`, differing only by a `python3.exe` copy in the venv `Scripts` directory
(details in docs/evidence/V3-manual-indexer.txt)
manual-venv850.scip          docs 91 {workspace sha: 17323, stdlib: 6303, click 8.1.7: 4806}
manual-venv850-python3.scip  docs 91 {workspace sha: 17323, stdlib: 6303, click 8.5.0: 4857}
                                             [V3-manual-indexer.txt]

Same document count, same workspace symbols, same stdlib; only the third-party
attribution moved from the Store 3.11's `click 8.1.7` to the chosen venv's
`click 8.5.0`. This is the explanation recorded in VERIFICATION.md §3.4 and
KNOWN_ISSUES Rank 6.
