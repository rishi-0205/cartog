## Test design note (no red for the script itself)

The script was prototyped while exploring grimp and madge, before its tests were
written. There is therefore no honest "red" transcript of the form "the script
does not exist yet". Instead the test is proved able to fail by mutation:
dropping one pair from `grimp_edges` (`pairs.discard(sorted(pairs)[-1])`) makes
`test_compare_imports_matches_fixture_edges` fail, and the mutation was reverted
before the final run.

`test_compare_imports_matches_fixture_edges` builds a package with a re-exporting
`__init__`, relative imports and a subpackage, asserts `cartog_edges(repo) ==
grimp_edges(repo)` (4 pairs), and asserts the report is `excluded == 0`,
precision 1.0, recall 1.0 with no discrepancy lists.
`test_compare_imports_reports_precision_recall` pins the set arithmetic
(3 vs 3 pairs, 2 shared -> 2/3 precision and recall, only_ours/only_theirs
lists) and that an empty side reports `None` instead of dividing by zero.
