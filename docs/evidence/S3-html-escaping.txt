What the fix does:

* `cartog/render/export_html.py::escape_json_for_script()` escapes `&`, `<`,
  `>`, U+2028 and U+2029 as JSON `\uXXXX` escapes before the payload is placed
  in `window.CARTOG_VIEW_DATA`. The test parses the payload back with
  `json.loads` and asserts the value is preserved, not truncated.
* Project name and rollup note interpolated in markup go through
  `html.escape(..., quote=True)`.
* `cartog/render/assets/viewer.js` now builds the sidebar with
  `createElement`/`textContent`/`replaceChildren`; the toolbar button labels use
  `textContent`. No `innerHTML`, `outerHTML`, `insertAdjacentHTML`,
  `document.write` or `eval(` remains.
* `map.html` carries
  `<meta http-equiv="Content-Security-Policy" content="default-src 'none';
  script-src 'unsafe-inline'; style-src 'unsafe-inline'; img-src data:;
  font-src data:; connect-src 'none'; base-uri 'none'; form-action 'none'">`.

The viewer is still valid JavaScript:

exit=0
