Date: 2026-11-19 18:02:00

## What the canary is

`tests/fixtures/hostile_repo/` is a small mixed Python/JavaScript repository
whose project files would write a marker if anything executed them:

* `package.json` -> `postinstall` writes `HOSTILE_NPM_MARKER`;
* `setup.py` -> writes `HOSTILE_SETUP_MARKER` next to itself.

Proof that both payloads are real (executed deliberately in `.scratch/`, never by
Cartog): `docs/evidence/S2-hostile-canary-armed.txt`.

This is a regression guard rather than a bug fix: the pipeline never had a code
path that runs project code, and the test now proves it stays that way. The red
run fails on the deliverable (the fixture + marker check) being absent, exactly
as U6's documented-example guard did.
