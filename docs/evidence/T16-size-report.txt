T16: Size and Token Budget Report
Evidence File

1. Objective & Scope
--------------------
Measure and report exact byte sizes of `graph.json` before and after compact serialization
(compact unindented schema 2.0.0 without redundant `contains` edges vs legacy indented with `contains` edges),
as well as architectural digest token sizes across Click, Flask, and Ky using `cl100k_base`.

2. Commands Executed
--------------------
Click Compact Graph:
$ venv\Scripts\python.exe -m cartog.cli build samples/click --out cartog-out/size-click-compact

Click Legacy Graph:
$ venv\Scripts\python.exe -m cartog.cli build samples/click --pretty --emit-contains --out cartog-out/size-click-legacy

Flask Compact Graph:
$ venv\Scripts\python.exe -m cartog.cli build samples/flask --out cartog-out/size-flask-compact

Flask Legacy Graph:
$ venv\Scripts\python.exe -m cartog.cli build samples/flask --pretty --emit-contains --out cartog-out/size-flask-legacy

Ky Compact Graph:
$ venv\Scripts\python.exe -m cartog.cli build samples/ky --out cartog-out/size-ky-compact

Ky Legacy Graph:
$ venv\Scripts\python.exe -m cartog.cli build samples/ky --pretty --emit-contains --out cartog-out/size-ky-legacy

Architectural Digest Generation:
$ venv\Scripts\python.exe -m cartog.cli digest samples/click --out cartog-out/digest-click
$ venv\Scripts\python.exe -m cartog.cli digest samples/flask --out cartog-out/digest-flask
$ venv\Scripts\python.exe -m cartog.cli digest samples/ky --out cartog-out/digest-ky
