## Retention semantics

`--keep N` (default `1`) counts complete runs per project, newest first. After
`finalize`, older complete runs are deleted, incomplete runs older than the
oldest kept complete run are deleted, and incomplete runs newer than that
boundary are kept for diagnosis. `latest/` is a copied directory of the newest
complete run, never a symlink; `--out` runs have no `latest` and are never
pruned. `N < 1` raises `ValueError`; the CLI rejects it as a usage error.
