T8 EVIDENCE: Name Collisions in Flat Dictionaries

1. PROBLEM & DIAGNOSIS
--------------------------------------------------------------------------------
Three flat dictionary collision issues were identified:
1. In cartog/merge.py:_pick_handler(), candidate matching strictly checked
   `start_line >= dec_end_line`. When functions are defined before routes (e.g.
   Express handlers or module functions defined above route declarations),
   _pick_handler() skipped preceding candidates and incorrectly picked distant
   subsequent functions, or fell back to flat last-seen names.
2. In cartog/merge.py parent containment, child symbols were linked to parents
   using `symbols_by_name[s.parent]`. When multiple classes shared a name (e.g.
   `Config` in different functions or namespaces), children were cross-pollinated
   to whichever class was parsed last.
3. In cartog/merge.py:627-650, SCIP candidate resolution populated
   `sym_node_map[(f.path, s.name)]` only once per file, causing all calls from or
   to same-named symbols in the same file to be misattributed to the first symbol.

6. IMPLEMENTATION DETAILS
--------------------------------------------------------------------------------
1. _pick_handler():
   - Prefers immediately following candidate (0 <= start_line - dec_end_line <= 5)
     for Python decorators.
   - Otherwise computes minimum absolute line distance to pick the closest candidate
     (supporting functions defined before routes as in Express/JS).
2. Parent containment:
   - Scopes parent lookup by prefix in qualified_name (s.qualified_name.rsplit(".", 1)[0]).
   - Filters candidates in symbols_by_name_list to those whose range encloses
     the child symbol (parent.range.start_line <= s.start_line <= parent.range.end_line).
3. SCIP candidate linking:
   - Keys sym_node_map by both (path, qualified_name) and (path, qualified_name, line).
   - Groups candidates by name in sym_nodes_by_name[(path, name)].
   - Resolves caller using evidence line range to identify the enclosing symbol.
   - When resolving ambiguous callee names, matches exact suffix on qualified_name.
