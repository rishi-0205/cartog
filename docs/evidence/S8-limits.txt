What the fix does:

* New `cartog/core/limits.py`: `AnalysisLimitError`; `enforce_file_count()`
  (default 50,000 files); `enforce_graph_size()` (default 200,000 nodes and
  500,000 edges). Each message names the exceeded count, the limit, and the
  flag that raises it.
* `_execute_parse()` accepts `max_files` and checks the discovered count before
  parsing; `analyze` passes it through.
* `analyze` checks the merged graph immediately after `build_graph()` and before
  `graph.json` is written, so an oversized run publishes no graph.
* Three flags on `analyze`: `--max-files`, `--max-graph-nodes`,
  `--max-graph-edges`. The existing `--max-file-size` remains the per-file
  exclusion threshold (files above it are listed as skipped, not truncated).
* `build_meta()` takes `limits` and writes them to `meta.json` for both
  `complete` and `failed` runs; the active values are visible even when the run
  aborts.
