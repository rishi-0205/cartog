## Implementation

* `cartog/scip/runner.py::is_call_selector()` — an occurrence is a `calls` edge
  only when it is the rightmost selector of the callee chain. Receivers become
  `references`/`receiver`. This is the Rank 1 fix.
* `cartog/scip/static_calls.py::resolve_chain_calls()` — walks `A.B.C(...)`
  through the caller's import map, re-exports and object-literal property
  initializers, then looks up `C` only in the container reached. Emits
  `calls` edges with `confidence="inferred"` and evidence `path:line`.
  Ambiguity, computed dynamic keys, spreads and `Object.assign` abstain.
* `cartog/graph/merge.py` — appends static candidates (deduped) after SCIP ones.
* `cartog/scip/static_calls.py` added to `docs/dev/PACKAGE_LAYOUT.md`.
